PREFEITURA MUNICIPAL DE CAJURI / MG - Injecao de layout no Portal Facil
Origem: https://cajuri.hom.portalfacil.com.br/ (layout replicado, visual identico)
Versao v2 (estrutura no esquema do Paineiras - backup da v1 em _backup-v1/)
==================================================================

OBJETIVO: replicar o layout atual de Cajuri SEM alterar o visual, no formato de
injecao (HTML + CSS colados no BackOffice), igual ao projeto Paineiras.

PALETA: azul-marinho #1B1F78 + laranja #F19727. Apoio: azul claro #DBEAFE,
        cinza #F3F4F6, texto #1F2937 / #333 / #4B5563 (paleta Tailwind do original).
TIPOGRAFIA: pilha padrao do sistema (ui-sans-serif, system-ui, Segoe UI...),
        a mesma do original - nao carrega fonte externa.

==================================================================
ARQUIVOS
==================================================================
- index_1.html    Home (injecao). Cole em "Importar codigo" (icone download).
- index_2.html    Paginas internas. Topo/rodape espelhados; <InternalContent>
                  FORA dos dois wrappers .nu (o portal estiliza o interno).
- cajuri.css      CSS UNICO (estilo + responsivo juntos). Suba como CSS custom.
- images/         Brasao, bandeiras, Radar, logo PortalFacil (SVG) e foto do hero
                  (todas JA EMBUTIDAS em base64 nos index; aqui so como fonte).
- preview.html    Preview standalone. NAO vai pro portal.
- PROMPT-MASTER.md  Prompt da migracao.
- LEIA-ME.txt     Este arquivo.
- _backup-v1/     Versao anterior (formato template completo, com css/ e js/).
- _captura/       Recortes do print usados na medicao e nas imagens do preview.

SEM PASTA js/: nao ha JavaScript proprio. O que era JS virou CSS puro:
- Contraste: checkbox escondido (#caj-contraste) + label "Contraste" no topo;
  o CSS usa body:has(#caj-contraste:checked). (Nao persiste entre paginas.)
- Parallax do hero: animacao por rolagem em CSS (animation-timeline). Em
  navegadores sem suporte a foto fica centralizada e parada (mesmo visual).
  Respeita prefers-reduced-motion.
- Idiomas: bandeiras EN/ES abrem o Google Tradutor; PT volta para "/".
- Ano do rodape: fixo "2026" (atualizar na virada do ano).
Unico script: <NextScript> do Bootstrap 5.3.3 (menu mobile e dropdowns).

==================================================================
COMO APLICAR NO PORTAL
==================================================================
1. GrapesJS > "Importar codigo" > colar index_1.html na home.
2. Repetir na pagina interna com index_2.html.
3. Subir cajuri.css como CSS custom do cliente.
4. Publicar e conferir no dominio real.

==================================================================
REGRAS DE INJECAO RESPEITADAS
==================================================================
- Wrapper class="nu" (nunca id). index_2 com DOIS wrappers, InternalContent fora.
- Classes proprias com prefixo caj-, tudo escopado sob .nu (nao colide com o tema).
- Zero comentarios HTML. Sem @import (icones por <link>), sem !important, sem @layer.
- Imagens em base64 nos index ({BASE_PATH} nao e substituido na injecao).
- Utilitarios do box com !important do Bootstrap (.py-2 do menu, .mb-1 do titulo
  da noticia) compensados por margem, sem brigar com !important.

v2.3 - BOTAO "VOLTAR AO TOPO" NO RODAPE
==================================================================
Botao redondo laranja (36px, seta azul) na barra final do rodape, ao lado do
logo Portal Facil. Sem JS: e um link para a ancora #caj-topo (id posto na
barra superior dos dois index), com rolagem suave por CSS
(html:has(.nu #caj-topo) { scroll-behavior: smooth }), desligada para quem
pede "reduzir movimento". Tem foco visivel no teclado e versao em alto
contraste. No celular fica centralizado abaixo do texto de direitos.

v2.4 - "VOLTAR AO TOPO" FIXO A DIREITA
Agora o botao fica FIXO no canto inferior direito da tela (24px das bordas;
16px no celular), 44px de diametro (area de toque confortavel), z-index 1100.
Continua no HTML do rodape (nada mudou nos index); o position:fixed o prende
a janela. Ele SURGE so depois que a pagina rola ~150-300px (animacao por
rolagem em CSS, animation-timeline: scroll()) e some de novo ao voltar ao
topo. Navegadores sem esse recurso: botao sempre visivel.
Nao conflita com o botao "Gerenciar cookies" do portal (lado esquerdo).

v2.5 - SUBMENUS ABREM NO HOVER
No computador (>= 992px) os submenus do menu principal (Governo, Secretarias
e qualquer item com filhos no BackOffice) abrem sozinhos ao passar o mouse,
com uma animacao curta; fecham ao tirar o mouse. Tambem abrem pelo teclado
(Tab, via :focus-within). So CSS. O clique do Bootstrap continua valendo.
Uma "ponte" invisivel de 10px evita que o submenu feche no caminho do mouse.
Subniveis abrem para a direita. No celular nada muda (abre pelo toque).
